“We propose a GenAI-driven healthcare document intelligence system that transforms unstructured medical reports into actionable clinical insights. The system employs a Retrieval-Augmented Generation (RAG) pipeline using LangChain and a vector database to perform semantic search, metadata-aware retrieval, and structured summarization of healthcare documents. Implemented with Flask and deployed on AWS, the solution integrates open-source large language models to ensure scalability, transparency, and cost-effective deployment while supporting safe and context-aware medical query handling.”
